# 员工差旅与报销管理制度

## 第一章 总则

第一条 为规范公司员工出差及费用报销管理，控制运营成本，保障员工合法权益，依据国家相关财务制度，结合公司实际情况制定本制度。

第二条 本制度适用于公司全体员工，包括试用期员工、正式员工及外派人员。

## 第二章 出差申请与审批

第三条 员工出差须提前填写《出差申请单》，写明出差事由、目的地、起止时间、预计费用，经部门负责人审批后方可出差。出差时间超过三天的，须报分管副总批准。

第四条 紧急出差可先电话或微信报备，返回后一个工作日内补办审批手续。未履行审批手续擅自出差的，费用不予报销。

## 第三章 差旅费用标准

第五条 交通费标准：
1. 高铁/动车：普通员工二等座，部门经理及以上可乘坐一等座；
2. 飞机：单程超过800公里方可乘坐经济舱，一律不得超标准乘坐头等舱；
3. 市内交通：凭票据实报实销，每日上限100元。

第六条 住宿费标准：
1. 一线城市（北京、上海、广州、深圳）：单人间每晚不超过500元；
2. 省会城市：单人间每晚不超过400元；
3. 其他城市：单人间每晚不超过300元；
4. 两人同行同性别的，应合住一个标准间，按一人标准报销。

第七条 伙食补助标准：市内出差每人每天80元，市外出差每人每天120元，不再报销餐费发票。

## 第四章 报销流程

第八条 员工应在出差返回后五个工作日内完成报销，逾期须说明原因。报销流程如下：
1. 整理票据，填写《费用报销单》并粘贴增值税发票；
2. 部门负责人审核费用真实性；
3. 财务部审核发票合规性及标准符合性；
4. 总经理或其授权人审批；
5. 财务出纳付款，付款周期一般为审批通过后三个工作日。

第九条 发票要求：报销发票须为增值税发票，抬头为公司全称及统一社会信用代码。电子发票须通过国家税务局查验平台验证真伪，重复报销一经发现按公司奖惩制度处理。

第十条 因公请客须提前报备，单次超过1000元的接待费用须总经理审批。

## 第五章 附则

第十一条 本制度由财务部负责解释和修订，自发布之日起执行。此前相关规定与本制度不一致的，以本制度为准。

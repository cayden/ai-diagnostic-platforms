# 数据安全管理规定

## 1 目的与适用范围

1.1 为保障公司数据资产安全，防止敏感数据泄露，依据《中华人民共和国数据安全法》《中华人民共和国个人信息保护法》制定本规定。
1.2 本规定适用于公司全体员工、外部合作方及所有接入公司信息系统的第三方人员。

## 2 数据分级管理

2.1 公司数据分为三个级别：
- 公开数据：可对外公开的产品介绍、宣传资料、招聘信息；
- 内部数据：仅限公司内部使用，如内部制度、生产计划、一般工艺文件；
- 机密数据：涉及客户信息、财务数据、核心工艺配方、源代码、招投标信息，须严格限制访问。

2.2 各业务部门须对本部门数据进行分级标识，机密数据须在文件、系统、介质上明确标注"机密"。

## 3 数据访问与使用

3.1 员工仅可访问本人岗位职责所需的数据，遵循最小授权原则。
3.2 机密数据的访问、复制、导出须经部门负责人及信息安全管理员双重审批，并全程留痕。
3.3 严禁私自将公司数据拷贝至个人移动设备、个人网盘或发送至个人邮箱。
3.4 涉及客户个人信息（手机号、身份证号、地址等）的批量导出，须经公司分管领导批准，并脱敏处理。

## 4 数据外发管理

4.1 向外部供应商、客户提供公司数据，须签订保密协议，明确数据使用范围与销毁期限。
4.2 禁止使用公有云大模型（如在线AI问答、在线翻译）上传公司内部及机密数据。
4.3 员工使用AI工具时，不得输入客户信息、财务数据、工艺配方等敏感内容。

## 5 数据存储与备份

5.1 重要数据须存储在公司内部服务器或经审批的私有云平台，禁止存储于个人设备。
5.2 核心数据库每日增量备份、每周全量备份，备份介质异地存放，每季度进行一次恢复演练。

## 6 账号与权限

6.1 员工账号遵循一人一号，离职当日注销账号，禁用共用账号。
6.2 密码须不少于10位并包含大小写字母、数字、特殊字符，每90天更换一次。
6.3 信息系统账号权限每半年复审一次，及时回收离职及调岗人员权限。

## 7 安全审计与违规处理

7.1 信息安全管理员每月审计一次系统日志，重点核查敏感数据访问记录。
7.2 发现数据泄露或疑似泄露，须在2小时内上报信息安全管理员，启动应急响应。
7.3 违反本规定者，视情节轻重给予警告、通报批评、解除劳动合同处理；涉嫌违法犯罪的，移交司法机关。
